# 可以云码考试系统 · 使用说明书

本文面向两类使用者：

- **学员**：刷题、看错题、参加考试、自己组卷自测
- **管理员**：管理题库、发布考试、查看练习统计、修改系统设置

两个入口：

| 入口 | 默认地址 |
| --- | --- |
| 学员端 | `http://localhost:5173` / 生产域名 |
| 管理端 | `http://localhost:5174` / 生产域名 |

管理员和学员使用同一套账号体系，但权限不同；管理员可以参与刷题和考试。

## 一、学员端

### 1. 登录

1. 打开学员端地址。
2. 输入用户名和密码。
3. 点击「登录」。

如果忘记密码，请联系管理员在「用户管理」中重置，或由管理员重新创建账号。

### 2. 首页

登录后进入首页，可以看到：

- 系统名称、副标题和 Logo（由管理端「系统设置」统一配置）
- 题库总量、待复习错题等概览
- 刷题、错题本、在线考试、视频教学、业务书籍等入口
- 公告栏，点击可查看公告详情

### 3. 顺序刷题

1. 首页点击「刷题」或「开始刷题」。
2. 选择题库分类和「顺序刷题」模式。
3. 系统会从**上次离开的位置**继续，不需要每次从头开始。
4. 选择答案后点击「提交」，系统即时显示对错和解析。
5. 答错的题会自动进入错题本。

> 如果换了一个分类，系统会按该分类的进度单独记忆。

### 4. 错题本

错题本分两个页签：

- **待复习**：答错且尚未掌握的题
- **已掌握**：答对后自动移出待复习的题

支持按日期筛选：

- 快捷项：今天、昨天、近 3 天、近 7 天、近 10 天
- 也可以手动选择开始日期和结束日期
- 只显示最近 10 天内的错题；超过 10 天的错题会由后端自动清理

在错题本里可以：

- 查看错题详情、正确答案和解析
- 点击「错题组卷」，把当前错题组成一套卷子，专门练错题
- 设置题目数量、总分和考试时长后开始作答

### 5. 自己组卷 / 自测

学员可以不依赖管理员，自己出一套卷子：

1. 进入「在线考试」或首页的「自己组卷」。
2. 选择题库分类。
3. 按题型设置数量，例如单选 10 道、多选 5 道、判断 5 道。
4. 设置总分、考试时长。
5. 点击「开始组卷」，系统从题库随机抽题。
6. 提交后查看得分、正确率和逐题解析。

> 如果某类题数量不足，页面会提示当前可用题量。

### 6. 在线考试

1. 进入「在线考试」。
2. 选择管理员已发布的考试。
3. 查看考试说明、题目数量、总分和时长。
4. 点击「开始考试」，在规定时间内作答。
5. 提交后查看成绩；也可以在「我的成绩」里查看历史记录。

考试答题过程中不会下发正确答案，提交后才显示解析（以实际页面为准）。

### 7. 个人中心与修改密码

点击首页头像或「我的」进入个人中心：

- 查看用户名、姓名、部门、岗位
- 查看「关于」信息：系统名称、版本、开发者
- 点击「修改密码」，输入当前密码和新密码
- 点击「退出登录」

### 8. 视频教学与业务书籍

首页的「视频教学」「业务书籍」由管理员在后台维护。没有内容时会显示空状态；有内容时点击卡片查看详情或打开资源地址。

## 二、管理端

### 1. 登录

打开管理端地址，使用管理员账号登录。默认账号：

```text
用户名：admin
密码：admin123
```

首次登录后请立即到「系统设置 → 账号安全」修改密码。

### 2. 数据概览

「数据概览」展示题库、用户、考试、答题量等汇总数据和图表，用于快速了解系统运行情况。

### 3. 题库管理

#### 分类管理

1. 进入「题库管理 → 分类管理」。
2. 新建分类，填写分类名称、排序和状态。
3. 支持父子分类；父分类下的题目可以在子分类中统一抽题。
4. 分类类型分为题库、视频、书籍，分别对应不同资源。

#### 题目列表

1. 进入「题库管理 → 题目列表」。
2. 可以新增、编辑、删除题目。
3. 单选题、多选题支持选项 A ~ J（最多 10 个选项）。
4. 可以设置正确答案、解析、分值、难度和题目图片。
5. 支持按分类、题型、关键词筛选。

#### 批量导入

1. 进入「题库管理 → 批量导入」。
2. 下载 CSV 模板，或按页面表头准备 Excel / CSV。
3. 必填列：分类 / 专业、题型、题干、正确答案。
4. 单选 / 多选至少填两个选项；判断题选项留空会自动生成“对 / 错”。
5. 正确答案填字母：单选 `A`，多选 `ABD`，判断 `对` / `错`。
6. 拖入文件后点击「开始导入」。
7. 导入结果会显示成功、重复跳过和失败行；失败行按提示修正后重新导入即可，成功的题不会重复入库。

> 单次最多 5000 道；导入前请先创建好分类。

### 4. 考试管理

1. 进入「考试管理」。
2. 点击「新建考试」，填写考试名称、说明、总分、时长、及格分、开始 / 结束时间。
3. 按题型设置抽题数量，系统从题库随机抽题。
4. 保存后发布考试。
5. 学员端即可看到该考试。
6. 在「考试成绩」中查看每个学员的得分、正确率和答题明细。

### 5. 练习统计

「练习统计」用于查看学员练习情况：

- 可按日期范围、专业、学员筛选
- 显示学员总数、有练习的学员、答题总量、整体正确率、统计天数
- 明细表按日期、学员、部门、岗位、专业展示答题量、答对数和正确率

管理员账号也参与刷题和考试，因此管理员的数据同样会出现在统计中。

### 6. 公告管理

1. 进入「公告管理」。
2. 新建公告，填写标题、内容和状态。
3. 发布后学员端首页公告栏展示。
4. 可以编辑、下线或删除公告。

### 7. 用户管理

1. 进入「用户管理」。
2. 新建学员账号，填写用户名、密码、姓名、部门、岗位。
3. 可以编辑、禁用、删除账号。
4. 学员忘记密码时，可由管理员重置。

### 8. 学习资源

「学习资源」用于维护视频和书籍：

- 视频：标题、简介、分类、视频地址、封面、排序、状态
- 书籍：书名、作者、简介、分类、封面、文件地址、排序、状态

### 9. 系统设置

「系统设置」是本次新增的品牌与账号管理页面。

#### 品牌设置

可以修改：

- 系统名称（例如「可以云码考试系统」）
- 副标题（例如「考试 · 刷题 · 组卷」）
- 系统 Logo（上传 JPG / PNG / WebP，最大 2MB）
- 开发者名称（例如「可以云码软件开发」）
- 页脚文字
- 备案号

操作：

1. 修改输入框内容。
2. 如需换 Logo，点击「上传新 Logo」，选择图片。
3. 点击「保存品牌设置」。
4. 保存后学员端、管理端侧栏、登录页、关于页会读取新配置。
5. 点击「恢复默认」可以清除上传的 Logo，使用内置默认图。

> Logo 建议 512×512 像素；上传后立即预览，保存后生效。

#### 账号安全

1. 输入当前密码。
2. 输入新密码（至少 6 位）。
3. 再次输入新密码。
4. 点击「修改密码」。
5. 修改成功后会自动退出，请用新密码重新登录。

#### 品牌预览

右侧会实时预览 Logo、系统名称、副标题和页脚，保存前可以先看效果。

### 10. 关于系统

侧栏底部「关于系统」展示：

- 系统版本
- 开发者
- 技术架构
- 部署环境
- 当前管理端地址
- 备案号

## 三、常见问题

### 学员端首页没有公告？

管理员需要先在「公告管理」发布一条状态为启用的公告。

### 错题本里的题越来越少？

系统只保留最近 10 天的错题，超过 10 天会自动清理。日期筛选里可以选择最近 10 天内的范围。

### 顺序刷题每次都从头开始？

请确认使用的是「顺序刷题」模式；系统按分类记录上次位置。如果清了浏览器缓存或换了账号，进度会重新开始。

### 自己组卷提示题目不足？

说明当前分类下该题型的可用题量少于设置数量。减少数量或换一个分类。

### 批量导入部分行失败？

按导入结果里的行号和原因修正。常见原因：

- 分类名称不存在
- 题型不是单选题 / 多选题 / 判断题
- 正确答案字母不在选项范围内
- 单选 / 多选选项少于两个
- 同一分类、同一题型、同一题干重复

### 修改系统名称后页面没变？

1. 确认点击了「保存品牌设置」。
2. 刷新页面（`Ctrl+F5`）。
3. 如果仍不生效，检查后端是否正常运行、`/api/site` 是否返回新名称。

### 上传 Logo 失败？

- 图片是否超过 2MB
- 格式是否为 JPG / PNG / WebP / GIF
- Nginx 的 `client_max_body_size` 是否设置为 25m
- 后端 `backend/uploads/` 目录是否有写权限

### 管理员忘记密码？

如果还能登录其他管理员账号，在「用户管理」中重置；如果全部管理员都无法登录，可在服务器上直接修改数据库中的密码哈希，或恢复备份。生产环境请保留至少一个可用的管理员账号。
